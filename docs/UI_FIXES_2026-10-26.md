## 可行性与实施

保留单入口和 App 独立目录。本轮沿用冷蓝玻璃壁纸与已生成的 16 枚图标，补生成 9 枚同风格图标。原来的黑框来自把整格图集（含外部黑色间隙）缩进图标容器。现在按每枚图标的实际范围定位图片，再使用统一圆角裁切，不再把间隙当作图标边缘。

1. 恢复上轮未推送的改动，并以远端 `feat/phone-framework` 为基准接续，保留其他提交。
2. 删除桌面“你好，熙蒙”“留一点时间给自己”和“另一面的世界”等文案。
3. `src/system/icon-assets.js` 统一映射全部 25 款 App。原图集保留，新图集为 `public/icons/glass-utilities.png`；开发者自定义图标优先。
4. 第二页换成真实提醒事项表：勾选完成、新增、删除、本机持久化。独立存储在 `content.reminders`，不把笔记误当待办。旧存档没有该字段时正常显示空表，首次新增自动创建字段。

6. 兼容 HTTP 本地预览缺少 `crypto.randomUUID` 的情况，新增共享本地 ID 工具，修复提醒、聊天、笔记和编辑器等创建记录的同类问题。
7. 测试、构建后同步原开发分支，并更新原私人预览站点。

## 后续补充：桌面去重与聊天编辑器

底栏仅电话、信息，两者从三页桌面移除；浏览器保留单一桌面入口，设置移到第三页。KIRA 是唯一邮件 App，旧 mail 链接转向 KIRA，保留历史入口兼容。

聊天编辑器新增联系人／群标题、发言人昵称、逐条发言人选择、显示时间、鼠标和触摸拖动排序、直接指定位置、复制消息。文字输入即时保存，保存与排序不再把编辑页面滚回顶部。

消息可以直接显示、到指定游戏日 HH:mm 出现，或进入对话延迟出现。运行时隐藏未触发的正文与聊天列表摘要；记录送达标记，避免刷新后重复出现。其他 App 中收消息会产生站内通知。支持预览触发、重新等待触发，编辑器打开时暂停运行时触发。旧消息和旧本机存档兼容。

`npm test` 现有 16 项通过。浏览器实测发言人切换、延迟前隐藏与到时显示、拖动后保存新顺序、KIRA 正文入口。手机触摸拖动采用同一 Pointer Events 实现，未声称已在真实 iPhone 上完成设备测试。
